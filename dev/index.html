ADRIAIndicators.jl

ADRIAIndicators.jl is a Julia package for summarizing outputs from coral reef ecological models. It provides a standardized, dependency-free way to transform high-dimensional model outputs, such as coral abundance by reef, time, species and size class, into lower-dimensional, interpretable metrics.

Functions range from simple aggregations and unit conversions to indices and regression-based estimators, covering functional diversity, juvenile abundance, shelter volume, fish biomass and overall reef condition.

Installation

ADRIAIndicators.jl requires Julia 1.11 or later.

using Pkg
Pkg.add("ADRIAIndicators")

See Usage to get started.

The ADRIA ecosystem

ADRIAIndicators.jl began as the metrics module of ADRIA.jl, a decision-support platform for evaluating coral reef interventions. It was separated out so that outputs from different models, or observational data, are summarized with the same definitions whether or not ADRIA.jl is used.

  • ADRIA.jl: computes its metrics with ADRIAIndicators.jl and feeds them into its decision-support algorithms.
  • CoralBlox.jl: the coral model used by ADRIA.jl, whose spatial-demographic projections are summarized by ADRIAIndicators.jl.
  • CscapeInterface.jl: uses ADRIAIndicators.jl to post-process C-scape simulation results for analysis in ADRIA.jl.
  • ReefGuide: a web-based assessment platform, with ADRIAIndicators.jl support planned.

Available metrics

  • Relative/Absolute/LTMP Cover
  • Relative/Absolute Shelter Volume
  • Relative/Absolute Juveniles
  • Juvenile Indicator
  • Coral Diversity
  • Coral Evenness
  • Reef Indices
